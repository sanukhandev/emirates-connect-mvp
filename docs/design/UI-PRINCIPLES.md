# UI Principles

## 1. Business-first clarity
Emirates Connect serves founders, entrepreneurs and business owners. Interfaces should optimize trust, identity, credibility, discovery and productive interaction rather than entertainment density.

## 2. Modern Bento, not visual clutter
Use Bento cards to establish hierarchy. A page should have a dominant task or content region with supporting modules, not a mosaic of equally loud cards.

## 3. Brand restraint
`#9470F8` is an accent and action color. Off-white and grey surfaces should carry most of the interface so content remains the focal point.

## 4. Consistency across web and mobile
Angular/Tailwind and Flutter use the same semantic colors, Ubuntu typography, spacing rhythm, radius language, icons and content hierarchy. Platform-specific navigation patterns are acceptable.

## 5. Content-first social design
Posts, comments, business updates and reels need strong authorship, timestamp/status clarity and readable interaction controls. Decorative chrome must not reduce content density or legibility.

## 6. Professional trust cues
Verification state, business ownership/role, moderation state and privacy boundaries must be clear and consistent. Never use ambiguous badge colors or UI patterns that could imply verification where none exists.

## 7. Responsive by composition
Do not merely shrink desktop layouts. Reorder or collapse supporting Bento modules around the primary user task at each breakpoint.

## 8. Accessible interaction
Every action must remain usable by keyboard and touch, with visible focus, sufficient target size and non-color status cues.
